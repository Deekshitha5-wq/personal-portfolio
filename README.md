# Personal Portfolio Web Application

## About the Project

This is a responsive and interactive personal portfolio website developed as part of the Full Stack Development assignment.

The portfolio presents my personal profile, educational background, technical skills, internship experience, projects, certifications, and contact information.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)

## Features

- Responsive navigation bar
- Personal profile and About section
- Education details
- Technical skills
- Internship experience
- Project showcase
- Project filtering using JavaScript
- Dark and Light mode
- Contact form
- Client-side form validation
- Responsive design for desktop, tablet, and mobile devices

## Projects Included

### 1. GitHub Profile Intelligence & Fake Account Detection
A full-stack application that analyzes GitHub profiles using the GitHub REST API and calculates Trust, Skill, Activity, and Risk scores.

### 2. Personal Expense Tracker
A simple Python application for recording and managing daily expenses and calculating total spending.

### 3. Student Grade Calculator
A simple Python program that calculates total marks, average percentage, and assigns grades using conditional statements.

## Interactive Features

### Dark/Light Mode
Users can switch between dark and light themes using the theme button in the navigation bar.

### Project Filtering
Users can filter projects by:
- All
- Full Stack
- Python

### Contact Form Validation
JavaScript validates the contact form and displays dynamic error or success messages.

## Responsive Design

The website uses Bootstrap's responsive grid system, CSS Flexbox, and media queries to provide a suitable layout across desktop, tablet, and mobile screen sizes.
